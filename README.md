# Fedora-gnome-rice-configs (RED)
This repo consists of my customized or tweaked config files for my gnome as well as some fixes to the problems I faced while setting up and ricing Fedora.
### files included

* `~/.config/gtk-4.0/gtk.css` - tweaked gtk4 styling
* `~/.themes/CyberDusk/gnome-shell/gnome-shell.css` - tweaked gnome-shell theme
* `~/.config/starship.toml` - my customized starship file with a red theme
* `gnome reboot on shutdown fix` 


### credits & notes

The CyberDusk theme was created by someone else (originally in blue). I don't own any of the original code, I just edited the css files to swap the blue hues for reds.
